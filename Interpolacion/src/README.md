## 📌 Descripción del Proyecto

Este repositorio contiene la implementación en Java de dos de los métodos fundamentales de interpolación polinómica:
1. **Método de Polinomios de Lagrange** (rutina completada según los requerimientos de la práctica).
2. **Método de Diferencias Divididas de Newton** (proporcionado por la asignatura).

El propósito del proyecto es analizar y comparar la precisión numérica, la estructura de código y la eficiencia computacional de ambos métodos ante un conjunto de nodos idénticos.
